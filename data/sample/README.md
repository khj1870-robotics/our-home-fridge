# 예시 데이터

실제 영수증·식단·이름 대신 쓸 예시 데이터를 둡니다. 실제 생활 데이터는 올리지 않습니다.

## 두 사람의 저녁 검산 사례

할인과 배송비가 없는 가상 영수증입니다. 테스트 시작 시 재고는 비어 있습니다.

| 품목 | 산 수량 | 결제액 | 분류 |
| --- | ---: | ---: | --- |
| 두부 | 1모 | 4,000원 | 식재료 |
| 달걀 | 6개 | 3,000원 | 식재료 |
| 수세미 | 1개 | 2,000원 | 생활용품 |

1. 영수증을 확정하면 가계부에 9,000원, 그중 식재료비 7,000원이 기록됩니다. 냉장고에는 두부와 달걀이 들어갑니다.
2. 두부의 기한을 내일로 입력합니다. 먼저 먹을 재료로 두부를 골라 두부 반 모와 달걀 2개를 두 사람의 저녁에 넣습니다.
3. ‘먹음’을 누르면 끼니 원가는 3,000원(두부 2,000원 + 달걀 1,000원), 1인 단가는 1,500원입니다. 외식 기준 1인 10,000원과의 차이는 1인 8,500원입니다.
4. 남은 재고는 두부 반 모와 달걀 4개로 총 4,000원입니다. 사용액과 잔액의 합은 식재료 구입액 7,000원입니다.
5. 같은 끼니를 다시 열거나 새로고침해도 차감은 한 번입니다. 별도 끼니에서 ‘건너뜀’을 선택해도 남은 수량과 가계부 결제액은 그대로입니다.
