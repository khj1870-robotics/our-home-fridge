# 앱 코드

독립 실행 버전(저장을 IndexedDB로 교체)을 만들면서 이 폴더로 옮깁니다. 지금 쓰는 본 앱은 Claude 아티팩트에서 동작합니다.

## 12월 6일 제출까지의 완료 기준

| 작업 기간 | 일정표 작업 | 확인할 결과 |
| --- | --- | --- |
| 11-23 ~ 11-24 | 범위 확정·저장소 만들기 | 제출 범위와 가상 시연 사례 확정. 테스트 사본에서 옮길 기능과 대상(본 앱 또는 독립판)은 사용자 확인 대기. |
| 11-25 ~ 11-28 | 독립 실행 버전 | 11/25~26 로그인 없이 샘플 재료 저장·복원. 11/27~28 장보기→요리 선택→먹음→남은 재고까지 연결. |
| 11-29 ~ 12-01 | 돈 계산 개편 6단계 | FIFO·할인 배분·원가 보존·중복 먹음 검산을 먼저 완료. 버린 돈 기록과 검산 표시의 추가 범위는 시연 후 결정. |
| 12-02 ~ 12-03 | 테스트·버그 수정 | 11/28 첫 사용자가 설명 없이 저녁을 정해 기록. 12/2~3 Android·iPhone에서 반복 입력·막힌 지점·새로고침 결과 확인. |
| 12-04 ~ 12-04 | README 작성 | 실행법·AI 실제/예시 구분·출처·샘플 화면·데모 링크 검토. |
| 12-05 ~ 12-05 | 실행 확인·제출 | 다른 환경에서 같은 커밋의 ZIP을 풀어 시연. 저장소 URL과 ZIP 제출 후 e-Class 상태 확인. |

첫 시연에서는 [예시 영수증](../data/sample/README.md)을 입력하고 임박한 재료를 골라 두 사람의 저녁을 기록합니다. 재고, 식비, 남은 재료를 확인한 다음 같은 끼니를 다시 열어봅니다. 시험 기기, 실제 결과, 막힌 단계는 개발 기록에 남깁니다. 과제 마감은 12월 6일 23:59이며 ZIP과 저장소 URL은 같은 버전을 가리켜야 합니다.
